# lob-lab

How much of a market maker's backtested P&L is an artefact of assuming fill-at-touch,
measured on real Deribit BTC-PERPETUAL data, and how much of the inventory-skew
advantage measured on synthetic paths in `vol-lab` survives a queue-aware fill model.

- The question and the hypotheses: `docs/spec.md`.
- The hypotheses, fixed before any data was collected: `docs/preregistration.md`.

## Status

Work in progress. Results are not in yet, so this README carries no numbers. When it
does, every number carries an uncertainty and the command that regenerates it.

## Limitations, stated up front

- The `raw` book interval requires an authenticated Deribit connection. This repository
  uses the public `100ms` interval, which aggregates changes inside each interval, so
  queue position between two snapshots is inferred rather than observed.
- No market data is committed here. Tests run on synthetic fixtures generated by the
  repository itself.
